# Mã và mẫu lịch sử

Các macro và ví dụ ở đây dùng API cũ, không được phát hành trong package 0.1.0
và không thuộc bộ ví dụ được hỗ trợ. Giữ nguyên để tham khảo khi chuyển tài liệu cũ.

`examples/demo.typ`, `examples/demo-new.typ`, `examples/main.typ` trước đây gọi
các macro hoặc đường dẫn không còn tồn tại. Ví dụ hiện hành nằm ở `../examples/`.
